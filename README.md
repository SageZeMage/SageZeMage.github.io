# Nassim Guetiteni - IST 256 Generative AI Portfolio

A responsive professional portfolio created for the IST 256 Generative AI web-profile activity. The site presents my education, professional experience, technical skills, and selected software projects.

## Portfolio contents

- `index.html` - portfolio structure and content
- `styles.css` - responsive layout, cards, navigation, light/dark theme styling
- `script.js` - persistent dark/light mode toggle
- `Nassim_Guetiteni_Resume.pdf` - downloadable current resume
- `.nojekyll` - tells GitHub Pages to serve the static files directly

## Features

- Responsive desktop, tablet, and mobile layout
- About Me, Experience, Technical Skills, Projects, Education, and Contact sections
- Persistent dark/light mode using JavaScript and `localStorage`
- Downloadable PDF resume button
- Direct GitHub and LinkedIn profile links
- Featured Steam Game Recommendation Engine project

## Run locally

Keep all files in the same folder and open `index.html` in a web browser. No installation or local server is required.

## GitHub Pages hosting

This repository is named `SageZeMage.github.io`, so after GitHub Pages is enabled from the `main` branch and repository root, the site should publish at:
