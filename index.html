Steam Game Recommendation Engine

A team-built content-based recommendation system developed during my Computer Science studies at Montgomery County Community College. The project processes Steam and SteamSpy game data, uses TF-IDF vectorization on game tags, and ranks similar titles using cosine-based similarity.

The PySimpleGUI interface allows a user to select one to three Steam games and returns ten recommendations for each selection, including each game's price and review rating. Data preparation and cleaning were performed with Python, pandas, NumPy, and Jupyter notebooks.
